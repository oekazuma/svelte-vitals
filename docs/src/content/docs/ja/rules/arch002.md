**重大度:** info · **カテゴリ:** architecture

## チェック内容

`$props()` から 10 個を超えるプロップを分割代入しているコンポーネントを検出します。レスト要素（`...rest`）や分割代入していない `$props()` はカウントしません。

## なぜ重要か

プロップの面積が大きいコンポーネントはたいてい責務過多です。関連するプロップをオブジェクトにまとめるか、コンポーネントを分割すると API が理解しやすくなります。

## 修正方法

```svelte
<script>
  // 多数のフラットなプロップではなく、関連するものをオブジェクトにまとめる。
  let { user, layout } = $props(); // user: { name, avatar, … }
</script>
```
