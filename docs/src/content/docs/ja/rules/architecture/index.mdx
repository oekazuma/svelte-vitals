コンポーネントの大きさと props の数 — 1 つのコンポーネントが抱えすぎているサイン。

| ルール                                                                 | 重大度  | 概要                                                   |
| ---------------------------------------------------------------------- | ------- | ------------------------------------------------------ |
| [`architecture/component-size`](/ja/rules/architecture/component-size) | 🔵 info | 巨大なコンポーネントは分割すべきです。                 |
| [`architecture/prop-count`](/ja/rules/architecture/prop-count)         | 🔵 info | 多くのプロップを受け取るコンポーネントは責務過多です。 |

{/* rules-index:end */}

ルールの重大度を変更したり無効にする方法は [設定](/ja/guides/configuration) を参照してください。
