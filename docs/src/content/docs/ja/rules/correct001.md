---
title: CORRECT001 · キー付き each ブロック
description: 動的データの {#each} にはキーを付けるべきです。
---

**重大度:** warning · **カテゴリ:** correctness

## チェック内容

キーのない `{#each}` ブロックを検出します。`src/` 配下のすべての `.svelte` コンポーネントを静的(CLI)解析します。定数のインライン配列リテラル(`{#each [1, 2, 3] as n}`)は長さが固定で並べ替えが起きないため、キーを付けても意味がなく対象外とします。

## なぜ重要か

キーがないと、リストの並べ替えや要素の挿入・削除時に Svelte は DOM ノードを破棄して作り直し、要素の状態(フォーカス・入力・トランジション)を失い、余計な処理を行います。キーがあれば既存ノードを照合して移動できます。

## 修正方法

```svelte
{#each items as item (item.id)}
  <li>{item.name}</li>
{/each}
```
