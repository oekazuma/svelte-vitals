---
title: SEO027 · 見出し階層
description: 各ページは <h1> をちょうど1つ持つべきです。
---

**重大度:** warning

## チェック内容

`<h1>` が 0 個(主見出しなし)、または 2 個以上(トピックの希薄化)のページを検出します。ちょうど 1 個で合格です。レイアウトチェーンの見出しもルートに数えるため、`+layout.svelte` の `<h1>` も認識されます。

## なぜ重要か

`<h1>` はページの主トピックを示す、最も強力なオンページ構造シグナルの 1 つです。欠けるとページに主見出しがなくなり、複数あると競合してトピックシグナルが弱まります。

## 修正方法

```svelte
<!-- +page.svelte -->
<h1>ページ唯一の、内容を表す説明的なメインの見出し</h1>
<h2>サブセクション</h2>
<h2>別のサブセクション</h2>
```

## モードによる違い

見出しは両モードで収集されますが、収集元が異なるため結果が食い違う場合があります。

- **静的(CLI)** はルートの `.svelte` テンプレートを走査するため、`{#if false}` のようにレンダリングされない分岐内の見出しも数える一方、インポートした子コンポーネントが描画する見出しは見えません。
- **レンダリング(vite)** は最終的な HTML を読むため、コンポーネントが描画した見出しを認識し、実際にレンダリングされた分岐のみを数えます。

両者が食い違う場合は、ブラウザに配信される内容を反映するレンダリング結果を信頼してください。
