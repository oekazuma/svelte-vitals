**重大度:** warning

## チェック内容

`<h1>` が 0 個（主見出しなし）、または 2 個以上（トピックの希薄化）のページを検出します。ちょうど 1 個で合格です。ページのレイアウトチェーンにある見出しもそのルートの集計に含めるため、`+layout.svelte` の `<h1>` もカウントされます。

## なぜ重要か

`<h1>` はページの主トピックを表す見出しで、オンページの構造シグナルとして最も強力なものの一つです。ないとページに主見出しがなくなり、複数あると互いに競合してトピックのシグナルが弱まります。

## 修正方法

```svelte
<!-- +page.svelte -->
<h1>ページ唯一の、内容を表す説明的なメインの見出し</h1>
<h2>サブセクション</h2>
<h2>別のサブセクション</h2>
```

## モードによる違い

両モードとも見出しを収集しますが、収集元が異なるため結果が食い違うことがあります。

- **静的（CLI）** はルートの `.svelte` テンプレートを走査します。そのため、`{#if false}` のようなレンダリングされない分岐の中にある見出しも数える一方、インポートした子コンポーネントが描画する見出しは見えません。
- **レンダリング（vite）** は最終的な HTML を読みます。そのため、コンポーネントが描画した見出しも認識し、実際にレンダリングされた分岐だけを数えます。

両者が食い違う場合は、レンダリング結果を信頼してください。ブラウザに配信される内容を反映しているのはそちらです。
