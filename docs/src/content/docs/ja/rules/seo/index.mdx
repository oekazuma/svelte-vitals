{/* rules-index:start */}

検索エンジンが実際に目にするもの。解決後の &lt;head&gt; メタデータ、構造化データ、クロールのしやすさを見ます。

| ルール                                                                 | 重大度      | 概要                                                                                                               |
| ---------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------ |
| [`seo/canonical-url`](/ja/rules/seo/canonical-url)                     | 🟡 warning  | すべてのルートに &lt;link rel="canonical"&gt; タグが必要です。                                                     |
| [`seo/charset`](/ja/rules/seo/charset)                                 | 🟡 warning  | 文字エンコーディングは &lt;meta charset&gt; で宣言します。                                                         |
| [`seo/description-length`](/ja/rules/seo/description-length)           | 🔵 info     | meta description は 70〜160 文字に収めましょう。                                                                   |
| [`seo/description-presence`](/ja/rules/seo/description-presence)       | 🔴 critical | すべてのルートに &lt;meta name="description"&gt; が必要です。                                                      |
| [`seo/duplicate-description`](/ja/rules/seo/duplicate-description)     | 🟡 warning  | meta description はルートごとに違う内容にしましょう。                                                              |
| [`seo/duplicate-title`](/ja/rules/seo/duplicate-title)                 | 🟡 warning  | &lt;title&gt; はルートごとに違う内容にしましょう。                                                                 |
| [`seo/heading-level-skip`](/ja/rules/seo/heading-level-skip)           | 🔵 info     | 見出しのレベルは飛ばさずに使いましょう。                                                                           |
| [`seo/hreflang`](/ja/rules/seo/hreflang)                               | 🟡 warning  | hreflang の alternate には有効なコードを使い、x-default も宣言しましょう。                                         |
| [`seo/html-lang`](/ja/rules/seo/html-lang)                             | 🟡 warning  | app.html の &lt;html&gt; に lang 属性を設定しましょう。                                                            |
| [`seo/image-alt`](/ja/rules/seo/image-alt)                             | 🟡 warning  | &lt;img&gt; には alt 属性を付けます。                                                                              |
| [`seo/indexability`](/ja/rules/seo/indexability)                       | 🔵 info     | ルートが誤って noindex になっていないか確認します。                                                                |
| [`seo/json-ld`](/ja/rules/seo/json-ld)                                 | 🔵 info     | どのルートにも JSON-LD 構造化データを入れましょう。                                                                |
| [`seo/json-ld-date-format`](/ja/rules/seo/json-ld-date-format)         | 🔵 info     | JSON-LD の日付プロパティは ISO-8601 形式で書きます。                                                               |
| [`seo/json-ld-deprecated-type`](/ja/rules/seo/json-ld-deprecated-type) | 🔵 info     | 一部のスキーマ型は、Google のリッチリザルトが廃止または制限されました。                                            |
| [`seo/json-ld-placeholder`](/ja/rules/seo/json-ld-placeholder)         | 🔵 info     | JSON-LD にプレースホルダのまま残っている値がないか確認します。                                                     |
| [`seo/json-ld-relative-url`](/ja/rules/seo/json-ld-relative-url)       | 🟡 warning  | JSON-LD の URL は絶対 URL で書きます。                                                                             |
| [`seo/json-ld-required-props`](/ja/rules/seo/json-ld-required-props)   | 🟡 warning  | 認識できる @type には、リッチリザルトに必要なプロパティを揃えましょう。                                            |
| [`seo/json-ld-validity`](/ja/rules/seo/json-ld-validity)               | 🟡 warning  | ページの JSON-LD は、@context と @type を備えた妥当な JSON である必要があります。                                  |
| [`seo/og-description`](/ja/rules/seo/og-description)                   | 🟡 warning  | og:description はどのルートにも入れましょう。                                                                      |
| [`seo/og-image`](/ja/rules/seo/og-image)                               | 🟡 warning  | &lt;meta property="og:image"&gt; タグはどのルートにも必要です。                                                    |
| [`seo/og-title`](/ja/rules/seo/og-title)                               | 🟡 warning  | &lt;meta property="og:title"&gt; タグはどのルートにも必要です。                                                    |
| [`seo/og-url`](/ja/rules/seo/og-url)                                   | 🔵 info     | og:url には、そのページの正規アドレスを入れましょう。                                                              |
| [`seo/robots-txt`](/ja/rules/seo/robots-txt)                           | 🟡 warning  | プロジェクトに robots.txt を用意しましょう。                                                                       |
| [`seo/single-h1`](/ja/rules/seo/single-h1)                             | 🟡 warning  | &lt;h1&gt; は 1 ページにつき 1 つだけにしましょう。                                                                |
| [`seo/sitemap-in-robots`](/ja/rules/seo/sitemap-in-robots)             | 🔵 info     | robots.txt から sitemap の場所をクローラーに伝えましょう。                                                         |
| [`seo/sitemap-xml`](/ja/rules/seo/sitemap-xml)                         | 🟡 warning  | プロジェクトに sitemap.xml を用意しましょう。                                                                      |
| [`seo/ssr-disabled`](/ja/rules/seo/ssr-disabled)                       | 🟡 warning  | export const ssr = false にすると、JS を実行しないクローラーからコンテンツが見えなくなり、初回描画も遅くなります。 |
| [`seo/title-length`](/ja/rules/seo/title-length)                       | 🔵 info     | &lt;title&gt; は 30〜60 文字に収めましょう。                                                                       |
| [`seo/title-presence`](/ja/rules/seo/title-presence)                   | 🔴 critical | どのルートでも &lt;title&gt; が空にならないようにしましょう。                                                      |
| [`seo/twitter-card`](/ja/rules/seo/twitter-card)                       | 🔵 info     | X/Twitter で大きなカード表示にするため、twitter:card を宣言しましょう。                                            |
| [`seo/viewport`](/ja/rules/seo/viewport)                               | 🟡 warning  | レスポンシブ表示のための viewport メタタグを宣言しましょう。                                                       |

{/* rules-index:end */}

ルールの重大度を変えたり、無効にしたりする方法は [設定](/ja/guides/configuration) を参照してください。
