---
title: SEO029 · 説明文の重複
description: 各ルートは一意の meta description を持つべきです。
---

**重大度:** warning

## チェック内容

静的な `<meta name="description">` の内容が(トリム・空白圧縮後に)同一の2つ以上のルートを検出します。動的・不在の説明文は検査しません。

## なぜ重要か

meta description が重複すると、検索エンジンにページ固有の要約を与えられず、無視されたり書き換えられたりします。

## 修正方法

```svelte
<svelte:head>
  <meta name="description" content="このルート固有の説明文。" />
</svelte:head>
```
