**重大度:** info

## チェック内容

すべての `<img>` 要素は明示的な `loading` 属性を持つ必要があります。`loading` 属性が欠落している画像は指摘されます。

## なぜ重要か

`loading` 属性により、ブラウザは画面外の画像の読み込みを遅延させることができます。なければ画像は積極的に読み込まれ、より重要なコンテンツの遅延を引き起こす可能性があります。静的解析ではどの画像が LCP かを判断できないため、これは助言的なものです。

## 修正方法

画面外の `<img>` 要素に `loading="lazy"` を追加します（LCP/ヒーロー画像は積極的なままにします）：

```svelte
<img src="/thumb.jpg" width="320" height="240" loading="lazy" alt="…" />
```
