# v1.0 rule-validity review — all 73 rules

Date: 2026-08-09
Status: Review record (findings only — fixes tracked separately)
Method: six parallel category reviewers (source + tests + docs en/ja + category design docs), every
Svelte/SvelteKit behavior claim verified against the Svelte MCP documentation server, web-standards
claims verified by fetching primary sources where reachable (tagged `[fetched]`) or labeled
`[unverified-knowledge]`, every shipped Svelte `fix.snippet` and docs "How to fix" snippet run
through `svelte-autofixer`, and detection-level claims re-verified empirically by the coordinator
against the built `packages/core/dist` before this record was written. Measured thresholds
(prop-count 6, component-size 200, title/description lengths) were treated as settled and only
their premises re-checked.

Headline: **38 of 73 rules fully SOUND; 35 carry at least one issue.** No rule is fundamentally
misconceived — every flagged issue is fixable by detection narrowing, severity/wording changes, or
docs corrections. Detection- or premise-level defects affect ~10 rules; the rest are severity
consistency questions and docs/message drift.

## Priority 3 — docs/message/test corrections (mechanical, no behavior change)

- **Stale limitations from #330/#399** (the largest cluster): `architecture/private-scope-import` docs claim custom `kit.alias` and `.svelte.ts` modules are unchecked (both now checked; Kit-module half still true — narrow, don't delete); `architecture/route-component-import` docs still exempt `.svelte.ts`/`.svelte.js` imports. En + ja, four files.
- **"static (CLI) only" leftovers**: `performance/lcp-image`, `performance/responsive-image`, `seo/image-alt` docs all claim static-only; all three run in rendered mode too (en + ja, six files). Sibling image docs carry no such claim — mutual inconsistency confirms leftover status. Plus one stale test label in `seo-static-gaps-rules.test.ts:61`.
- **Overstatements vs sources**: `seo/html-lang` ("declares language for search engines" — Google states it ignores `lang`); `seo/viewport` ("Google penalizes" — unsupported; the defensible claim is the 980px-viewport rendering behavior); `seo/canonical-url` ("must" + trailing-slash example moot under SvelteKit's own normalization); `seo/robots-txt` / `seo/sitemap-xml` / `seo/json-ld` docs "must have/include" → "should"; `performance/image-dimensions` "triggers CLS" → "can trigger… unless the box is reserved another way (CSS `aspect-ratio`)".
- **Fix-snippet polish**: `seo/image-alt` placeholder `alt="Description of the image"` trips Svelte's `a11y_img_redundant_alt` (use a concrete example); `correctness/nonreactive-builtin-state` teaches `$state(new SvelteSet())` — autofixer: wrapper unnecessary (bare construction is the documented idiom); `performance/preconnect` machine snippet lacks the `crossorigin` gstatic line its own doc shows (also: the design-time blocker for checking preconnect `crossorigin` coverage is gone — `hasCrossorigin` is collected; optional detection upgrade).
- **Small docs gaps**: five headTagRule docs describe only "Missing", not the "Empty" finding (og-image/og-title/og-url/twitter-card/canonical-url; description-presence already correct); `architecture/directory-naming` docs list four diagnostic cases, impl emits five ("value names no casing at all"); `heading-level-skip` lacks the Mode-differences block its data-sibling `single-h1` has; `doc-link-target` doesn't document `--route` silence; `route-component-import` doc implies `+error` has an `@` breakout form (it doesn't; impl correct).
- **Test guards**: `reserved-directory-names-example.test.ts` pins the pre-#409 two-map example (add `anyCaseUnitScopes` + a lowercase-unit path); no test exercises headTagRule's "Empty" branch; `unit-entry-file-example.test.ts` says "verbatim" while deviating (explained inline — drop the word).
- **javascript-url framing**: literal-only detection means every flagged URL is author-written; reframe rationale to CSP/navigation/semantics with XSS as parenthetical; sync the attribute list (formaction is covered but unlisted in the rationale).
