Agent Skills moved to skills.sh: the `/svelte-vitals` and `/improve-svelte` skills are now distributed from the repository's `skills/` directory and installed with `npx skills add oekazuma/svelte-vitals` (see https://www.skills.sh/), instead of being generated by the installer. `svelte-vitals install` no longer offers the `claude-skill` / `claude-skill-improve` targets, and `install --refresh` now only regenerates the Cursor rules file (`cursor-rules`). SKILL.md files previously written by the installer are left on disk untouched — reinstall them once via `npx skills add` and update them from then on with `npx skills update`.
